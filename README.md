# LPU Touch Demo (Android)

This is an offline demo/prototype. It uses dummy data only and does not connect to LPU systems.

## Open/build
1. Install Android Studio.
2. Open this folder as a project.
3. Let Gradle sync.
4. Connect an Android phone or use an emulator.
5. Run the `app` configuration.
6. To make an APK: Build > Build APK(s).

Demo PIN: any 6 digits (for example 123456).

Note: The biometric/fingerprint screen is represented as a demo-friendly PIN flow in this starter. Real device biometric authentication can be added with AndroidX Biometric if desired.
